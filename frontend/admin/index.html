Inscrire / mettre à jour une année universitaire

Crée (ou met à jour) la ligne d'historique d'un étudiant pour une année universitaire donnée : c'est ce qui lui permet d'avoir un relevé de notes calculable pour cette année-là. Utile pour rattraper une inscription oubliée ou corriger un parcours.

🎓 Clôture globale de l'année académique (Promotion et Redoublement automatiques)

Le système calcule automatiquement les moyennes des 2 semestres pour tous les étudiants inscrits pour cette année : ceux qui ont validé passent automatiquement au niveau supérieur (ex: L1 → L2 → L3 → M1 → M2) pour l'année suivante, avec ouverture automatique des dettes si nécessaire. Les étudiants non admis sont automatiquement inscrits en redoublement.
